# Google Play Store Analytics Dashboard | Tableau Project

An interactive Tableau dashboard developed to analyze Google Play Store application data and generate insights related to app performance, installs, ratings, and category trends.

## Key Insights
- Free apps dominate the Play Store market
- Game and Tools categories have the highest installs
- App ratings vary significantly across categories
- User engagement patterns can be identified through installs and reviews

## Dashboard Components
- KPI Cards
- Bar Charts
- Category Analysis
- Install Trend Visualizations
- Interactive Filters
